# JARVIS — Guía de Comandos CLI

## Generales

| Comando | Descripción |
|---------|-------------|
| `salir` / `exit` / `cerrar` / `quit` | Cierra JARVIS |
| `status` | Muestra estado de todos los módulos cargados |
| `reparar` | Ejecuta AutoRepair (verifica e instala dependencias) |
| `plataforma` / `platform` | Muestra información del sistema operativo |
| `ayuda` / `help` / `comandos` | Muestra esta ayuda |

## Aprendizaje y Memoria

| Comando | Descripción |
|---------|-------------|
| `aprender <clave> = <valor>` | Enseña un hecho a JARVIS |
| `recuerda <clave>` | Recupera un hecho aprendido |
| `olvida <clave>` | Elimina un hecho específico |
| `que sabes` / `conocimientos` | Lista todos los hechos, preferencias y conversaciones |
| `conversaciones` / `historial` | Muestra interacciones recientes |

## Motor de Conocimiento

| Comando | Descripción |
|---------|-------------|
| `buscar <consulta>` | Busca en la base de conocimiento local |
| `aprende de <url>` | Absorbe contenido de una URL |
| `temas` | Lista todos los temas disponibles en el conocimiento |
| `olvida tema <tema>` | Elimina un tema completo del conocimiento |
| `stats conocimiento` | Estadísticas del motor de conocimiento |

## Inteligencia Artificial

| Comando | Descripción |
|---------|-------------|
| `ia <pregunta>` | Consulta a todos los backends IA disponibles |
| `ia backends` | Lista backends IA disponibles (Ollama, OpenAI, Anthropic, Gemini) |

## Reconocimiento Facial

| Comando | Descripción |
|---------|-------------|
| `reconocer <ruta_imagen>` | Reconoce un rostro en una imagen |
| `registrar rostro <ruta> <nombre>` | Registra un rostro nuevo con nombre |
| `detectar rostros <ruta>` | Detecta todos los rostros en una imagen |
| `comparar rostros <a> <b>` | Compara dos imágenes faciales |

## Servidor Web

| Comando | Descripción |
|---------|-------------|
| `web on` / `web start` / `web iniciar` | Inicia el servidor web remoto |
| `web off` / `web stop` / `web detener` | Detiene el servidor web |
| `web url` / `web ip` | Muestra la URL de acceso |

## Automatización

| Comando | Descripción |
|---------|-------------|
| `abre <app>` | Abre una aplicación o sitio web |
| `busca archivo <nombre>` | Busca archivos en el sistema |
| `apagar` / `reiniciar` | Apaga o reinicia el equipo |
